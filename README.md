# О проекте

Данный проект демонстрирует полный цикл автоматизации тестирования:
- **E2E тестирование** ключевых пользовательских сценариев
- **Архитектура** на основе Page Object Pattern
- **CI/CD** с GitHub Actions
- **Профессиональные практики** написания автотестов

# Команды
npm test             # Все тесты
npm run test:headed  # С браузером
npm run test:debug   # Режим отладки
npm run report       # HTML отчет
